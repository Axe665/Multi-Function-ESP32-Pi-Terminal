# 计算器：Android 平板双栏 + 手机计算器功能（2026-11-01）

> 范围：`Main.qml` 的计算器段（section 6）。逻辑与界面都在这一处，没有新文件。

## 1. 布局

宽度 ≥ 760×uiScale 时走双栏（Android 平板计算器）：

```
┌─────────────────────────┬──────────────────────────┐
│ 7×8 =                   │ √ x² 1/x π sin cos ( )   │
│ 56                      │ AC ⌫ % ÷                 │
│ ─────────────────       │ 7  8  9  ×               │
│ 历史          清空       │ 4  5  6  -               │
│ 7×8 = / 56              │ 1  2  3  +               │
│                         │ ±  0  .  =               │
└─────────────────────────┴──────────────────────────┘
```

窄屏退回单栏：显示区在上、键盘在下，历史折叠成一块固定高度。

## 2. 功能

- 基础：`AC`、`⌫`、`%`、四则、小数点、`±`、`=`；
- 科学（一排）：`√`、`x²`、`1/x`、`π`、`sin`、`cos`、`(`、`)`；
- 表达式求值：递归下降解析，支持括号、负号、`×÷%`，`%` 按百分比（`/100`）处理；
- 历史：最近 20 条 `{表达式, 结果}`，左侧列表展示，可一键清空；
- 一元科学函数只作用于表达式末尾那个数（替换尾部数字），不会破坏前面的算式。

## 3. 视觉（Material 3）

- 按键方形小圆角（`shapeMedium`），横向铺满格子；
- 数字键 `surfaceContainerHigh`、运算符键 `primaryContainer`；
- `=` 用 `accent` 填充、`accentInk` 文字；
- 显示区是 `surface` 圆角卡片：上面表达式小字（右对齐、可省略左侧），下面结果大字 DemiBold；
- 科学排用 `surfaceContainer` 的小键，和主键盘拉开层级。

## 4. 验证

- `7 × 8 =` → 显示区 `56`、表达式行 `7×8 =`、历史出现一条 `7×8 = / 56`；
- 截图：`calculator-tablet.png`（初始）、`calculator-history.png`（算完后）。

## 5. 左右对调（同日）

按反馈把计算区与显示区对调：**键盘在左、显示与历史在右**。

- 键盘栏固定占 55% 宽，显示栏吃掉剩余宽度；
- 用 `Layout.row/column` 绑定实现：双栏时键盘 (0,0)、显示 (0,1)；
  单栏（<760）时显示回到第一行、键盘第二行，不会出现"键盘在上"的倒序。
