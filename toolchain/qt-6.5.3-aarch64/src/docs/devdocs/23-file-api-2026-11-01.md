# 文件 API / 外置 daemon（2026-11-01）

> 收尾状态、验证命令和上线阻塞项见
> [2026-11-01 收尾状态](24-final-status-2026-11-01.md)。

## 已完成

- `orange-pi-file-daemon`：每用户进程，Unix socket + 0700 socket + token 文件；
  只接受同 UID 宿主，模块 worker 不能直连。
- `FileApiBroker`：宿主侧唯一客户端，负责启动/连接 daemon、读写 framing、app 数据根。
- `FileApi`：模块 QML 的 `appFiles.request(op,args)`；宿主按模块实例的
  `NetworkGate.moduleFileAllowed` 判定，默认拒绝。
- C 模块：`pi_host_services.file_request` 经 worker `appRequest(kind=file)` 转发到宿主。
- 模块调用 `appFiles.requestWriteAccess()` 请求用户选择可写位置；宿主弹出
  文件/目录选择，选择后签发默认 24 小时的写授权。授权按 manifest id 持久化，
  应用重启后恢复未过期授权；卸载只撤销当前会话 token。
- daemon 只接受宿主用会话 token 做 HMAC-SHA256 签名的 capability：
  `{appId, appRoot, readRoot, writeRoot, expires}`。伪造或过期 capability
  直接拒绝，daemon 不再信任请求里的裸 root。
- `FileApi.writeGrantExpiresAt` 暴露过期时间；单文件授权只允许写该文件。
- 操作：stat/list/read/write/mkdir/rename/remove/ping；读/写分块，单块上限 1 MiB。
- 边界：家目录只读；每包
  `~/.local/share/orange-pi-terminal/apps/<manifest.id>/` 可写；
  `.ssh`、`.gnupg`、`.pki`、`.password-store`、keyrings、浏览器/终端配置、
  其他应用数据和 `.netrc`/`.git-credentials` 默认拒绝。
- 管理员联网页为声明 `file_api=home-read` 的模块增加“文件访问（家目录只读）”开关；
  和模块联网开关一起写入 root 策略 `network-policy.json` 的 `modules` 对象，
  保存需要管理员 PIN。
- worker unit 改为 `ProtectHome=yes`，模块包只从 root 管理的
  `/usr/lib|/usr/local/lib/orange-pi-terminal/modules` 只读路径加载。

## 尚未完成 / 明确限制

- 授权持久化在用户 QSettings，默认 24 小时；同一 UID 的进程仍可修改它。
- 本机 systemd user 服务已实测启动和 socket 0700；Pi 实机按用户要求跳过。
- 跨会话恢复是“恢复未过期授权”，不是 root 级长期策略；管理员关闭文件权限
  后 API 会拒绝，但 QSettings 里的授权记录仍在到期前存在。
- 真实文件选择器在 Pi 触摸环境下的可用性未验证。
