## 走查发现并修复的问题

### 1. 1024×600 启动时隐藏页布局告警

启动日志出现：

- `SettingsGroup.qml:74: ColumnLayout: Layout polish loop`；
- `WeatherTools.qml:145: ColumnLayout: Layout polish loop`。

原因是 StackLayout 把未显示的设置页/天气页压到 0～1px，页面内的换行 ColumnLayout
仍参与 polish。修复：

- 设置页整页改为按 `section===4` 延迟创建；
- 天气页主预览列和天气设置层分别用 Loader 延迟创建；
- `SettingsGroup` 在隐藏的 1px 卡片上不排版正文；
- CI 不受影响：天气页测试以 `active=false` 创建但宽度有效，仍会构建内容。

### 2. `TimeSyncSettings` / `TimeTools` 自绑定

打开设置页时出现：

`TimeSyncSettings: Binding loop detected for property "timeSync"` / `"alarmEngine"`。

`timeSync:timeSync` 在子组件内解析到子组件自己的同名 property，形成自绑定。
Main 增加 `timeSyncBackend` / `alarmBackend` 两个显式别名，设置页与时间页都通过
`win.timeSyncBackend` / `win.alarmBackend` 注入。

### 3. 电视页在拒网状态仍请求台标

联网关闭时打开电视，`TvPlayer.qml:625` 反复打印 `QQuickImage: 代理拒绝连接`。
台标只应在电视通道允许时请求；新增 `channelLogoSource()`，http(s) 台标在门控关闭时
返回空字符串，本地资源不受影响。

### 4. 2× 桌面登录页的绑定循环

把同一实例放到 DPR=2 的桌面展示时，登录页启动日志出现：

- `PinPad.qml:154: CarButton: Binding loop detected for property "implicitWidth"`；
- `LoginPage.qml:385/436: Dialog: Binding loop detected for property "implicitHeight"`。

确认键改为固定尺寸的 `IconButton`；关机/关于两个 Dialog 的正文改为打开时才构建。
重登后登录页、桌面首页均为 0 QML 告警。

### 5. 二级页残留到下一个应用、右侧滑入/滑出失效

人工操作：设置 → 联网权限 → 直接点应用右上角关闭 → 打开计算器，计算器窗口里
仍盖着「各功能联网权限」；关闭设置时该页还会在右侧滑出位置短暂悬空。录屏确认
联网页关闭时瞬间消失，没有 240ms 滑出。

根因与修复：

- 二级页是 `appShell` 的常驻子项，原 `closeApp` 只清模块页，不清
  `aboutDeviceOpen` / `networkPermissionsOpen` / `connectionSettingsOpen` /
  `developerPanelOpen` / `testModeOpen`。这些状态被下一个应用继承。
- 新增 `closeAuxiliaryPanels(true)`，在关闭、最小化、任务栏切换、打开新应用时
  清状态、关闭页内弹层并 `hideImmediately()`。
- 新增 `RightSlidePage.qml` 作为开发者选项、关于本机、联网权限、连接设置、
  测试模式、天气设置的公共壳：`visible` 只由显式 `shown` 状态决定，不再用
  `x < width` 推断；关闭时保留到 240ms 滑出结束再隐藏。
- 联网权限页的 Loader 首次打开后保持实例；原实现每次关闭即销毁、每次打开新建，
  新建时 `open` 已是 true，`x` 直接为 0，所以滑入/滑出都不存在。
- `appShell.clip: true`，滑出过程不会在应用窗口外再画半截页面。

回归：自动测试新增联网权限页打开/关闭中间帧、关闭应用后切换到文件页的断言；
人工录屏确认滑入/滑出均为 240ms OutCubic，计算器不再显示上一个应用的菜单。

## 天气/校时联网配置结果（补充）

用户反馈“开关打开仍不能联网”后，继续排查并修正为：

- `NetworkPolicy::defaults()` 现在会给受限应用预填官方域名：
  - 天气：Open-Meteo、地理编码、OpenWeather、MET Norway；
  - 校时：WorldTimeAPI、timeapi.io；
  - 音乐：本机 Node 与网易云 CDN。
- 联网权限页在打开受限应用且域名为空时，会自动填入推荐域名；保存前仍可删改。
- 旧策略文件中“未启用且 hosts 为空”的条目在加载时会补推荐清单；“已启用但
  hosts 为空”保持为空，避免把显式拒绝静默变成放行。
- 当前 root 策略已配置为：**仅天气和网络校时启用**，其余四项应用保持拒绝：
  - 天气 hosts：`api.open-meteo.com`、`geocoding-api.open-meteo.com`、
    `api.openweathermap.org`、`api.met.no`；
  - 校时 hosts：`worldtimeapi.org`、`timeapi.io`。
- 运行时代理策略同步后，`34004`（天气）和 `34005`（校时）通道实测 HTTP 200；
  天气页显示珠海实况（Open-Meteo，25°C）；时间页自动校时成功。

排查中还发现：演示实例为了隔离把 `XDG_RUNTIME_DIR` 指到临时目录，而当时已运行的
`network_proxy` 读取的是 `/run/user/1000/orange-pi-net-policy.json`，导致宿主写的
运行期策略落到了另一个路径。已改用正常运行时目录并同步；正常桌面启动不会出现
这个路径分叉。
