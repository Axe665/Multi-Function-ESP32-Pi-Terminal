# 浏览器虚拟摇杆（Joystick 控制网页滚动）

## 目标

为触屏浏览器增加一个**屏幕上的虚拟摇杆**，功能范围**仅限滚动当前网页内容**
（上下/左右）。不包含光标、点击或任何导航操作。面向适老化场景：控件加大、
面板可拖动换位，不需要任何新硬件与原生依赖。

## 使用

1. 浏览器工具栏新增「摇杆」按钮，页面右下角也有常驻徽章；点开即展开面板。
2. 面板顶部长条可拖动整块面板换位置。
3. 按住圆盘中的摇杆并推动：推得越远滚动越快；**向上推页面向上滚，向下推向下滚**，
   左右推做水平滚动；松手立即停止。
4. 摇杆中央约 12% 为死区，拇指搭着不推动时页面保持静止、不抖动。
5. 「收起」收回面板，滚动随即停止。

## 实现

全部逻辑在 `pi_terminal/qml/BrowserJoystick.qml` 一个文件内，Main.qml 只加了
一个工具栏按钮和组件实例，符合“功能单独文件、不污染 Main”的仓库约定：

- 滚动：16 ms 定时器每 3 帧（约 20 Hz）按摇杆偏移量注入一次
  `window.scrollBy(dx,dy)`；偏移经死区归一化后乘以每帧 36 px 上限，速度与
  推杆幅度成正比。
- 面板拖拽用 `DragHandler`（只抓长条把手），摇杆用 `MultiPointTouchArea`，
  二者互不干扰；面板为悬浮覆盖层，不拦截页面原有触摸。
- 不需要 C++：`runJavaScript` 是 WebEngineView 既有 API，测试里用假视图替换。

## 测试（功能 / 界面 / 性能）

一键入口（构建 + 运行三层测试并输出汇总）：

```sh
pi_terminal/tests/run_joystick_tests.sh               # 功能 + 界面 + 性能
pi_terminal/tests/run_joystick_tests.sh --benchmark   # 仅性能层，打印 JOYSTICK_BENCH_* 指标
```

| 层 | 测试 | 覆盖内容 |
|---|---|---|
| 功能 | `browser_joystick_cursor` | 方向正确（上推→`scrollBy(0,-36)`、右推→`scrollBy(36,0)`）、死区内零注入、松手后停止注入、toggle 开关、无目标视图时不注入 |
| 界面 | `browser_joystick_ui` | 徽章/面板可见性切换、摇杆滑块几何随 stickX/Y 变化、摇杆与按钮 ≥48px（适老化触控目标）、面板在 800×600 与 360×480 下均不出界 |
| 性能 | `browser_joystick_performance` | 满偏滚动注入速率（5–40 次/s，防失控循环）、setStick 调用吞吐、空闲面板 500 ms 零注入 |

## 实机验证清单

1. 触屏推杆上下左右：滚动方向正确、速度随推杆幅度增大、松手立即停止。
2. 拇指搭在死区内页面不抖动。
3. 长页面（新闻/文档站）滚动流畅，与手指直接滑动页面互不冲突。
4. 无痕标签页与普通标签页切换后摇杆仍作用于当前页。
5. 拖动面板换位后摇杆工作正常；展开/收起反复切换无卡顿。
6. 跑 `run_joystick_tests.sh` 三层全绿，记录 `JOYSTICK_BENCH_*` 指标。
