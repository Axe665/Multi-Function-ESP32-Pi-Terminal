# 安心浏览 · 方向轮盘

一个**独立重做**的适老化网页方向轮盘原型。它使用原生 HTML、CSS 和 JavaScript，不依赖旧仓库源码或第三方包；旧仓库只用于理解功能需求与交互边界。此目录已有的 GitHub `origin` 保持不变，本项目不会自动提交或推送。

## 运行

用浏览器直接打开 `index.html` 即可体验。页面包含普通文章、独立嵌套滚动区，以及“大字”和“高对比”设置。

- 触屏或鼠标：按住轮盘并往上、下、左、右拖动；松开立即停止。
- 顶部“摇杆：开/关”按钮可以显示或隐藏轮盘；关闭时会先停止滚动，且轮盘不再进入键盘焦点。
- 键盘：聚焦轮盘后按方向键滚动，按 Escape 停止。
- 控制当前光标经过或聚焦的滚动区域；区域到边界后继续滚动外层页面。遵守网页的 `overscroll-behavior`，不越权访问跨域 iframe。
- 中心死区避免误触；X 字形边界把圆盘分成四个区域，斜向输入归入最近的单一方向。
- 失焦或切换到后台时停止；每帧的滚动量有限，保持操作可控。

## 测试

测试覆盖方向映射、死区、速度上限、嵌套区域滚动、边界传递、overscroll 限制及重复初始化。测试脚本是标准 JavaScript ES module，可在支持 ES modules 的 JavaScript 引擎中运行。例如安装 GJS 的 Linux 环境：

```sh
gjs -m tests/run-tests.js
```

这个原型不是原仓库内 Qt/QML 浏览器的补丁；移植到终端产品仍需单独集成、在目标 Qt 版本构建，并进行触屏和树莓派实机验证。
